# Raw data goes here

Put the Iowa Liquor Sales CSV files in this folder (all years, all parts).

- Source: Iowa Liquor Sales on data.iowa.gov (Iowa Alcoholic Beverages Division)
- I downloaded one set of files per year, split into parts, 2017 to Oct 2026.
- Do not commit these files. They are about 25 million rows.
- If a part file is a full copy of another part, that is fine. The ETL removes exact duplicate rows.
